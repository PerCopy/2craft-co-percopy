## No lockfile — use npm install not npm ci
- Title: npm ci fails — no package-lock.json in build context
- Failed reason: `npm ci` requires a lockfile; package-lock.json is listed in .gitignore and is not committed
- Root cause: .gitignore excludes `package-lock.json` so it is never in the build context; `npm ci` with `COPY package.json package-lock.json* ./` gets no lockfile and errors
- Fix: Changed Dockerfile to `COPY package.json ./` and `RUN npm install --ignore-scripts` instead of `npm ci`
